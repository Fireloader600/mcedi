Mod 制作教程

用 EdiPack 制作第一个 MinecraftEdi Mod。整个过程不需要联网，依赖全部放在本地 gradle/lib/ 目录。

准备项目结构 Step 1

新建一个文件夹（例如 MyFirstMod），按下面的结构放文件：

MyFirstMod/ ├── settings.gradle ├── gradle.properties ├── build.gradle ├── gradle/ │ └── lib/ │ └── MinecraftEdi-0.19.jar ← 手动放入 └── src/main/ ├── java/com/example/ │ └── ModBlock.java └── resources/ ├── edimod.json └── assets/myfirstmod/textures/block/ └── ruby.png

把游戏项目打包出来的 MinecraftEdi-0.19.jar 放进 gradle/lib/，Mod 编译时就能引用到 EdiMod 接口和 BlockRegistry 类。

编写 Gradle 文件 Step 2

settings.gradle

rootProject.name = 'MyFirstMod'

gradle.properties

这里填写 Mod 的名字、版本和主类，会替换到 edimod.json 里。

modName=MyFirstMod
modVersion=1.0.0
mainClass=com.example.ModBlock

build.gradle

plugins {
    id 'java'
}

def modName    = project.property('modName')
def modVersion = project.property('modVersion')
def mainClass  = project.property('mainClass')

repositories {
    // 不联网，只从 gradle/lib 拿依赖
}

dependencies {
    implementation fileTree(dir: 'gradle/lib', include: ['*.jar'])
}

processResources {
    def modNameVal    = modName
    def modVersionVal = modVersion
    def mainClassVal  = mainClass
    inputs.property 'modName',    modNameVal
    inputs.property 'modVersion', modVersionVal
    inputs.property 'mainClass',  mainClassVal
    filesMatching('edimod.json') {
        expand(
            modName:    modNameVal,
            modVersion: modVersionVal,
            mainClass:  mainClassVal
        )
    }
}

jar {
    archiveBaseName = modName
    archiveVersion  = modVersion
}

编写方块类 Step 3

src/main/java/com/example/ModBlock.java。这个类实现 EdiMod 接口，游戏启动时会被 EdiPack 调用。 

package com.example;

import com.fire.block.BlockRegistry;
import com.fire.mod.EdiMod;

public class ModBlock implements EdiMod {

    @Override
    public void onInit(BlockRegistry registry) {
        // 注册一个名为 ruby 的方块，纹理来自本 mod jar 内：
        //   assets/myfirstmod/textures/block/ruby.png
        int id = BlockRegistry.register(
                "ruby",
                "/assets/myfirstmod/textures/block/ruby.png"
        );
        System.out.println("[MyFirstMod] ruby 方块已注册, id = " + id);
    }
}

编写 edimod.json Step 4

src/main/resources/edimod.json。这是 Mod 的元数据文件， 里面的 ${...} 会被 Gradle 用 gradle.properties 里的值替换。 

{
    "name":    "${modName}",
    "version": "${modVersion}",
    "main":    "${mainClass}"
}

把 ruby.png 放到 src/main/resources/assets/myfirstmod/textures/block/ruby.png， 建议使用 16×16 的 PNG。

编译与安装 Step 5

在 MyFirstMod/ 目录下执行：

gradlew build

构建产物在 build/libs/MyFirstMod-1.0.0.jar。把它复制到 MinecraftEdi 运行目录下的 mods/ 文件夹（首次运行游戏会自动创建）， 重新启动游戏即可。

启动后控制台会看到：

[EdiPack] 已创建 mods/ 文件夹
[EdiPack] 注册方块: ruby (id=3)
[EdiPack] 已加载: MyFirstMod v1.0.0 (MyFirstMod-1.0.0.jar)

资源包教程

资源包格式与原版 Minecraft 资源包相似，区别是 pack.mcmeta 改名为 package.edimeta。资源包用来覆盖内置方块的贴图。

准备目录结构 Step 1

在 MinecraftEdi 运行目录下的 resourcepacks/ 里新建一个文件夹， 名字随意（例如 BlueGrass），结构如下：

resourcepacks/ └── BlueGrass/ ├── package.edimeta └── assets/ └── minecraft/ └── textures/ └── block/ ├── grass.png ← 覆盖草方块 └── stone.png ← 覆盖石头

首次启动游戏会自动创建 resourcepacks/ 文件夹。 只有包含 package.edimeta 的文件夹才会被识别。

编写 package.edimeta Step 2

文件结构与原版 pack.mcmeta 完全一样，只是文件名改了。 

{
    "pack": {
        "pack_format": 1,
        "description": "我的资源包 - 把草方块改成蓝的"
    }
}

替换贴图 Step 3

把你想要替换的 PNG 放到 assets/minecraft/textures/block/， 文件名与内置方块保持一致即可覆盖。例如：

  • grass.png — 覆盖草方块
  • stone.png — 覆盖石头

尺寸建议 16×16，风格不限。启动游戏后控制台会打印： 

[EdiPack] 资源包: BlueGrass - 我的资源包 - 把草方块改成蓝的

Mod 方块的贴图也能被覆盖 进阶

Mod 方块的贴图路径由 Mod 作者决定。如果 Mod 使用了 /assets/myfirstmod/textures/block/ruby.png，那么资源包只需提供：

resourcepacks/ └── MyPack/ ├── package.edimeta └── assets/myfirstmod/textures/block/ └── ruby.png

路径与 Mod 内部声明的路径一致，就会覆盖 Mod 自带贴图。

如何运行

从下载到进入游戏只需要三步。

1

安装 Java 17 或更高版本

前往 adoptium.net 下载适合你系统的 JDK，安装后确认终端里能执行：

java -version
2

下载 MinecraftEdi-0.19.jar

点击上方的下载按钮，把 jar 保存到任意目录。

3

运行

双击 jar 即可启动；如果双击无效，在 jar 所在目录打开终端：

java -jar MinecraftEdi-0.19.jar

首次运行会在当前目录创建 mods/ 和 resourcepacks/ 两个文件夹。
